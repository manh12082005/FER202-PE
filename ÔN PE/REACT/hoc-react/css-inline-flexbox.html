🔄 CSS thường vs CSS inline trong React

Cú pháp CSS viết trong file .css khác với khi viết trực tiếp trong JSX (inline style)

🎨 CSS thuần (file .css)
/* Dùng dấu gạch ngang "-" */
.box {
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #61dafb;
  font-size: 16px;
  border-radius: 8px;
}
⚛️ CSS Inline trong React JSX
// Dùng camelCase, giá trị là string
const style = {
  display: "flex",
  justifyContent: "center",
  alignItems: "center",
  backgroundColor: "#61dafb",
  fontSize: "16px",
  borderRadius: "8px",
};

📏 4 Quy tắc vàng khi viết CSS inline trong React

Nắm vững 4 điều này là bạn không bao giờ bị lỗi khi dùng inline style

1
camelCase thay vì kebab-case (bỏ dấu -, viết hoa chữ tiếp theo):
background-color → backgroundColor  |  justify-content → justifyContent
align-items → alignItems  |  border-radius → borderRadius
2
Giá trị là string " " hoặc number:
"flex", "center", "16px", "#fff" → đặt trong dấu nháy kép
fontSize: 16 → số nguyên React tự thêm px
3
Dùng hai cặp ngoặc nhọn {{ }} khi viết trực tiếp trong JSX:
Ngoặc ngoài { } → biểu thức JavaScript trong JSX
Ngoặc trong { } → object JavaScript chứa style
4
Phân cách bằng dấu phẩy , (không phải ;):
Vì inline style là JavaScript object, không phải CSS text
{ display: "flex", justifyContent: "center" } ✅ đúng
{ display: "flex"; justifyContent: "center" } ❌ sai

✍️ 2 Cách viết CSS Inline trong JSX

Cách 1 viết trực tiếp, Cách 2 tách biến – khuyến khích dùng Cách 2 cho code sạch hơn

Cách 1 – Viết trực tiếp (Double curly braces {{ }}) 
function App() {
  return (
    <div
      style={{
        display: "flex",
        justifyContent: "center",
        alignItems: "center",
        height: "100vh",
        backgroundColor: "#0d1117",
      }}
    >
      <h1 style={{ color: "#61dafb", fontSize: "32px" }}>Hello React!</h1>
    </div>
  );
}
Cách 2 – Tách ra biến const (Recommended ✅) 
function App() {
  // Khai báo style object bên ngoài return
  const containerStyle = {
    display: "flex",
    justifyContent: "center",    // căn giữa trục ngang (main axis)
    alignItems: "center",        // căn giữa trục dọc (cross axis)
    height: "100vh",
    gap: "20px",                  // khoảng cách giữa các con
    flexDirection: "row",         // hướng: row | column
    flexWrap: "wrap",             // xuống dòng khi hết chỗ
    backgroundColor: "#0d1117",
  };

  const titleStyle = {
    color: "#61dafb",
    fontSize: "32px",
    fontWeight: "bold",
    margin: "0",
  };

  return (
    <div style={containerStyle}>
      <h1 style={titleStyle}>Hello React!</h1>
    </div>
  );
}

💡 Mẹo & Lỗi Thường Gặp

✅
Số nguyên không cần đơn vị
fontSize: 16 → React tự thêm px
Chỉ áp dụng cho property nhận đơn vị px.
❌
Đừng dùng dấu chấm phẩy
Sai: display: "flex"; color: "red"
Đúng: display: "flex", color: "red"
Đây là JS object!
ℹ️
Style động với biến State
color: isActive ? "blue" : "gray"
opacity: isLoading ? 0.5 : 1
⚠️
Inline style độ ưu tiên cao nhất
Inline style ghi đè CSS class. Dùng cho style động, dùng class cho style tĩnh.
🚀
Kết hợp nhiều style với spread
style={{ ...baseStyle, ...activeStyle }}
🎯
Không dùng được :hover inline
Inline không hỗ trợ :hover, :focus… Dùng CSS class hoặc state để xử lý.

⚡ Quick Reference – justifyContent & alignItems

Tất cả giá trị hay dùng nhất của 2 property quan trọng nhất

justifyContent: "flex-start"
Sắp xếp về đầu trục ngang (bên trái)
justifyContent: "flex-end"
Sắp xếp về cuối trục ngang (bên phải)
justifyContent: "center"
Căn giữa trục ngang ⭐ Hay dùng nhất
justifyContent: "space-between"
Phân đều, item đầu/cuối dính cạnh
justifyContent: "space-around"
Phân đều, có space ở hai đầu
justifyContent: "space-evenly"
Khoảng cách bằng nhau hoàn toàn
alignItems: "flex-start"
Căn về đầu trục dọc (trên cùng)
alignItems: "flex-end"
Căn về cuối trục dọc (dưới cùng)
alignItems: "center"
Căn giữa trục dọc ⭐ Hay dùng nhất
alignItems: "stretch"
Kéo giãn items theo chiều dọc (mặc định)
alignItems: "baseline"
Căn theo đường baseline của text
💡 Combo hay dùng nhất
display: "flex"
justifyContent: "center"
alignItems: "center"

🆚 style="..." trong HTML vs style={{ }} trong React

Đây là điểm khác biệt quan trọng – cùng kết quả nhưng cú pháp hoàn toàn khác nhau

<!-- Phân cách bằng dấu ; -->

<div style="display: flex;

🔲 CSS Grid System – Chia Layout

Grid là hệ thống chia cột/hàng mạnh nhất, thay thế Bootstrap grid bằng CSS thuần

grid-template-columns cơ bản
.container {
  display: grid;
  /* 3 cột bằng nhau */
  grid-template-columns: 1fr 1fr 1fr;
  /* hoặc viết tắt */
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;   /* khoảng cách */
}

⚖️ Khi nào dùng Flexbox, khi nào dùng Grid?

📏
Dùng Flexbox khi...
✅ Layout 1 chiều (ngang hoặc dọc)
✅ Navbar, menu, button group
✅ Căn giữa 1 phần tử
✅ Items có kích thước linh hoạt

display: flex
🔲
Dùng Grid khi...
✅ Layout 2 chiều (cả ngang + dọc)
✅ Chia trang thành Header, Sidebar, Main
✅ Gallery, card grid đều nhau
✅ Muốn control chính xác vị trí từng ô

display: grid
